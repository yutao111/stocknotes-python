StockNotes Windows 版使用说明
=============================

1. 将整个 StockNotes 文件夹解压到本地磁盘，不要只复制 StockNotes.exe。
2. 双击 StockNotes.exe，程序会自动打开浏览器。
3. 如果浏览器没有自动打开，请访问：http://127.0.0.1:5001
4. 使用期间请勿关闭 StockNotes.exe 对应的进程；退出时可在任务管理器中结束 StockNotes.exe。

数据说明
--------

- stocknotes.db 是全部本地数据，请定期备份。
- 数据库与 StockNotes.exe 位于同一目录，升级程序时不要覆盖或删除 stocknotes.db。
- 程序仅监听本机 127.0.0.1，不会作为局域网服务对外开放。
- 行情同步功能需要联网，首次同步可能需要较长时间。

常见问题
--------

- Windows Defender 首次运行可能提示未知发布者，这是未购买代码签名证书导致的。
- 若提示端口被占用，请先在任务管理器中结束之前启动的 StockNotes.exe。
- 文件夹路径建议使用普通中文或英文字符，并确保当前用户有写入权限。
